# 前端界面（`demo/`）

## 它是干什么的？

这里是 **CV Helper 的正式前端**，不是「只能本地演示、不能上云」的临时页。

- 主文件：`standalone.html`（登录、经历库、模拟面试、笔记本、知识汇总、管理员等）
- 后端在 `main.py` 里把本目录挂到 **`/ui`**
- **本机**打开 `http://127.0.0.1:8000/` → 跳到 `/ui/standalone.html`
- **云主机**部署同一仓库后，公网访问的也是这一页

`src/` 下的 React/Vite 是更早的结构草稿，**当前以 `standalone.html` + 后端为准**。

## 本机怎么跑

先起后端，再打开浏览器（推荐走同端口，少踩跨域）：

```bash
cd CV_Helper/backend
source .venv/bin/activate
uvicorn app.main:app --reload --port 8000
```

打开：**http://127.0.0.1:8000/**

也可直接用浏览器打开本目录的 `standalone.html`（默认请求 `http://127.0.0.1:8000`）；若提示未连接，先确认 uvicorn 已启动。

## 建议体验路径

1. **注册 / 登录** — 数据按账号隔离  
2. **经历库** — 手动添加或导入简历  
3. **模拟面试** — 提问 → 作答 → 深挖 → 标记 → 知识汇总  
4. **刷新页面** — 确认追问树与知识条目还在  
5. **笔记本 / 知识汇总 / 真实面经** — 看归档与复盘  

## 和云端的关系

| | 说明 |
|--|------|
| 代码 | 本地改 `standalone.html` → `git push` → 云上 `git pull` 后重启即可 |
| 配置 | `backend/.env` 各环境各自维护（API Key、JWT 等），不进 Git |
| 数据 | 默认 SQLite 在各自机器上；云挂了不会自动回到本机，除非你备份了数据库文件 |

接真实大模型：见 `../docs/接真实大模型.md`。  
公网部署：见 `../docs/部署上线.md`。
