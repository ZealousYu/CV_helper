# 部署上线（同一套代码：本机 ↔ 公网）

当前形态：FastAPI + SQLite，前端就是仓库里的 `demo/standalone.html`（挂在 `/ui`），**不是另做一套云端页面**。本地能跑的，推到 GitHub 后在云上 `pull`/Docker 部署即可公网访问。支持注册登录与按账号数据隔离；管理员可在「我的」查看用户数据。适合小范围分享，不是大型 SaaS。

> 阿里云大陆机若用**域名 + 80/443**，通常需要 ICP 备案；未备案时可用 `http://公网IP:8000/` 访问。

## 选 Railway 还是 Render？

| | Railway | Render |
|--|---------|--------|
| 长期免费 | 基本没有（试用额度用完后要花钱） | 有免费 Web，但**闲置会休眠**，下次打开要等几十秒 |
| 个人常用成本 | Hobby 约 **$5/月**（含等额用量，小项目常刚好盖住） | 要常开着 ≈ 付费档；白嫖则忍受冷启动 |
| 体验 | 连 GitHub、加磁盘、环境变量都顺 | 也成熟，Blueprint 也好用 |
| 适合你现在 | **自己用、偶尔打开也想秒开** → 选它 | **一分钱不想花、能忍慢启动** → 选它 |

**结论（个人站）**：

- 国内支付、要稳定网址 → **阿里云轻量**（推荐你现在走这条）  
- 有国际卡、想少运维 → Railway Hobby / Render  
- 纯白嫖试水 → Render Free（常要国际卡，且会休眠）

GitHub 仓库：`https://github.com/ZealousYu/CV_helper`（推送后可在服务器 `git pull` 再部署）。

## 推荐：阿里云轻量应用服务器

### 1. 买机器
1. 打开阿里云 → **轻量应用服务器**（不是必须上云服务器 ECS，轻量更简单）。  
2. 地域选离你近的（如华东/华南）。  
3. 镜像选 **Ubuntu 22.04**。  
4. 套餐 **1 核 2G** 起步够个人用；系统盘 40G+ 即可。  
5. 用支付宝完成购买。

### 2. 放行端口
控制台 → 该实例 → **防火墙**：**放行 TCP 80**（以及若你坚持用 8000 再放行 8000）。  
之后用浏览器访问：`http://公网IP/`。

### 3. 登录服务器
控制台点 **远程连接**，或本机：

```bash
ssh root@你的公网IP
```

### 4. 把代码弄上服务器（任选一种）

**A. 用 GitHub（推荐，方便以后更新）**

```bash
apt-get update -y && apt-get install -y git
git clone https://github.com/ZealousYu/CV_helper.git
cd CV_helper
```

若仓库是私有的，改用带权限的 HTTPS/SSH 克隆。

**B. 本机打包上传**

在你的 Mac 上：

```bash
cd /Users/xmiles/cursorProject/CV_Helper
tar czf /tmp/cv-helper.tgz --exclude .git --exclude backend/.venv --exclude '**/.env' .
scp /tmp/cv-helper.tgz root@你的公网IP:/root/
```

服务器上：

```bash
mkdir -p /root/CV_helper && tar xzf /root/cv-helper.tgz -C /root/CV_helper
cd /root/CV_helper
```

### 5. 一键部署

```bash
bash scripts/deploy-aliyun.sh
```

第一次会生成 `.env.production`，用编辑器改密码：

```bash
nano .env.production
# 至少改：ACCESS_PASSWORD=你的密码
# 建议确认：JWT_SECRET 已是随机串；可选填 ADMIN_USERNAME / ADMIN_PASSWORD
bash scripts/deploy-aliyun.sh
```

浏览器打开 `http://公网IP/`，输入访问密码即可。

### 6. 以后更新

```bash
cd /root/CV_helper   # 或你的项目目录
git pull             # 若用 GitHub
bash scripts/deploy-aliyun.sh
```

数据在服务器 `/var/lib/cv-helper`，更新代码一般不会清库。

### 7. （可选）域名和 HTTPS
域名解析到这台机的公网 IP，再用 Nginx + Let’s Encrypt 做 `https://你的域名`。先 IP 能打开再弄域名即可。

## 上线前必做

1. **设置访问密码**（强烈建议）  
   环境变量 `ACCESS_PASSWORD=你的密码`  
   开启后，陌生人打开链接会先看到解锁页，否则谁有链接都能读写你的经历，并可能消耗你的 LLM / 语音额度。

2. **配置模型密钥**（可选）  
   - `LLM_PROVIDER=openai`  
   - `LLM_API_KEY=...`  
   - `LLM_BASE_URL` / `LLM_MODEL`（如 DeepSeek）  
   - 豆包读题：`DOUBAO_TTS_API_KEY=...`

3. **数据库持久化**  
   容器内默认：`DATABASE_URL=sqlite:////data/cv_helper.db`  
   平台上请挂载磁盘到 `/data`，否则重启后数据会丢。

## 推荐：Railway

1. 把 `CV_Helper` 推到 GitHub（该目录是独立 git 仓库）。
2. 打开 [railway.app](https://railway.app) → New Project → Deploy from GitHub → 选仓库。  
   - Root Directory / 工作目录设为仓库根（即含 `Dockerfile` 的 `CV_Helper`）。
3. 会使用本目录的 `Dockerfile` + `railway.toml`。
4. **添加 Volume**，挂载路径填 `/data`（否则重启丢库）。
5. Variables 至少设置：
   - `ACCESS_PASSWORD` = 你的访问密码（强烈建议）
   - `DATABASE_URL` = `sqlite:////data/cv_helper.db`
   - 需要真模型时再填 `LLM_PROVIDER` / `LLM_API_KEY` / `LLM_BASE_URL` / `LLM_MODEL`
   - 豆包读题可选：`DOUBAO_TTS_API_KEY`
6. Settings → Networking → Generate Domain，得到 `https://xxx.up.railway.app`。  
   打开后若设了密码，先解锁再进助手。

试用额度用完后开 Hobby（约 $5/月）一般就够个人用量。

## 备选：Render（想白嫖、能忍冷启动）

1. 把 `CV_Helper` 推到 GitHub。
2. [Render Dashboard](https://dashboard.render.com) → New → Blueprint，或 Web Service + Docker。  
   Root Directory = `CV_Helper`。
3. 确认磁盘挂载 `/data`，环境变量同上。
4. Free 档闲置会休眠，首开较慢；要稳定再升到付费档。

本仓库已带 `render.yaml` / `Dockerfile`。

## 本地用 Docker 自测（需已装 Docker）

```bash
cd CV_Helper
docker build -t cv-helper .
docker run --rm -p 8000:8000 \
  -e ACCESS_PASSWORD=demo123 \
  -e LLM_PROVIDER=mock \
  -v cv_helper_data:/data \
  cv-helper
```

浏览器打开 http://127.0.0.1:8000/

## 临时给别人看（电脑需开机）

不想正式上云时，可用内网穿透（如 Cloudflare Tunnel / ngrok）把本机 `8000` 暴露出去。仍建议开 `ACCESS_PASSWORD`。这不是稳定网站，只适合短时演示。

## 已知限制（接受后再上线）

| 点 | 说明 |
|----|------|
| 账号隔离 | 用户名密码注册/登录，数据按账号隔离；管理员可在「我的」查看用户摘要 |
| 免费档休眠 | Render Free 闲置会冷启动，首开较慢 |
| 语音听写 | 依赖浏览器能力；HTTPS 下麦克风权限更顺 |
| 安全 | `ACCESS_PASSWORD` 是站点门槛；账号 JWT 负责数据隔离，公网请改 `JWT_SECRET` |

## 环境变量速查

| 变量 | 含义 |
|------|------|
| `ACCESS_PASSWORD` | 站点访问密码；空=不启用 |
| `JWT_SECRET` | 登录令牌密钥；公网务必修改 |
| `JWT_EXPIRE_DAYS` | 登录有效天数，默认 30 |
| `ADMIN_USERNAME` / `ADMIN_PASSWORD` | 预置管理员；遗留无主数据会挂到该账号 |
| `DATABASE_URL` | 默认容器内 `sqlite:////data/cv_helper.db` |
| `LLM_PROVIDER` | `mock` / `openai` |
| `LLM_API_KEY` | 模型 Key |
| `LLM_BASE_URL` / `LLM_MODEL` | 兼容 OpenAI 的接口 |
| `DOUBAO_TTS_API_KEY` | 豆包读题（可选） |
| `PORT` | 云平台一般自动注入 |
