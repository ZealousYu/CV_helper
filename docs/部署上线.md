# 部署上线（把本地 Demo 变成可公网访问的网站）

当前形态：FastAPI + SQLite + `/ui/standalone.html` 同端口提供。适合个人使用；**不是多用户 SaaS**。

## 选 Railway 还是 Render？

| | Railway | Render |
|--|---------|--------|
| 长期免费 | 基本没有（试用额度用完后要花钱） | 有免费 Web，但**闲置会休眠**，下次打开要等几十秒 |
| 个人常用成本 | Hobby 约 **$5/月**（含等额用量，小项目常刚好盖住） | 要常开着 ≈ 付费档；白嫖则忍受冷启动 |
| 体验 | 连 GitHub、加磁盘、环境变量都顺 | 也成熟，Blueprint 也好用 |
| 适合你现在 | **自己用、偶尔打开也想秒开** → 选它 | **一分钱不想花、能忍慢启动** → 选它 |

**结论（个人站）**：没什么人用、但希望打开就可用 → **优先 Railway**；纯白嫖试水 → Render Free。

下面默认按 **Railway** 写；Render 步骤仍保留在文末。

## 上线前必做

1. **设置访问密码**（强烈建议）  
   环境变量 `ACCESS_PASSWORD=你的密码`  
   开启后，陌生人打开链接会先看到解锁页，否则谁有链接都能读写你的经历，并可能消耗你的 LLM / 语音额度。

2. **配置模型密钥**（可选）  
   - `LLM_PROVIDER=openai`  
   - `LLM_API_KEY=...`  
   - `LLM_BASE_URL` / `LLM_MODEL`（如 DeepSeek）  
   - 豆包读题：`DOUBAO_TTS_API_KEY=...`

3. **数据库持久化**  
   容器内默认：`DATABASE_URL=sqlite:////data/cv_helper.db`  
   平台上请挂载磁盘到 `/data`，否则重启后数据会丢。

## 推荐：Railway

1. 把 `CV_Helper` 推到 GitHub（该目录是独立 git 仓库）。
2. 打开 [railway.app](https://railway.app) → New Project → Deploy from GitHub → 选仓库。  
   - Root Directory / 工作目录设为仓库根（即含 `Dockerfile` 的 `CV_Helper`）。
3. 会使用本目录的 `Dockerfile` + `railway.toml`。
4. **添加 Volume**，挂载路径填 `/data`（否则重启丢库）。
5. Variables 至少设置：
   - `ACCESS_PASSWORD` = 你的访问密码（强烈建议）
   - `DATABASE_URL` = `sqlite:////data/cv_helper.db`
   - 需要真模型时再填 `LLM_PROVIDER` / `LLM_API_KEY` / `LLM_BASE_URL` / `LLM_MODEL`
   - 豆包读题可选：`DOUBAO_TTS_API_KEY`
6. Settings → Networking → Generate Domain，得到 `https://xxx.up.railway.app`。  
   打开后若设了密码，先解锁再进助手。

试用额度用完后开 Hobby（约 $5/月）一般就够个人用量。

## 备选：Render（想白嫖、能忍冷启动）

1. 把 `CV_Helper` 推到 GitHub。
2. [Render Dashboard](https://dashboard.render.com) → New → Blueprint，或 Web Service + Docker。  
   Root Directory = `CV_Helper`。
3. 确认磁盘挂载 `/data`，环境变量同上。
4. Free 档闲置会休眠，首开较慢；要稳定再升到付费档。

本仓库已带 `render.yaml` / `Dockerfile`。

## 本地用 Docker 自测（需已装 Docker）

```bash
cd CV_Helper
docker build -t cv-helper .
docker run --rm -p 8000:8000 \
  -e ACCESS_PASSWORD=demo123 \
  -e LLM_PROVIDER=mock \
  -v cv_helper_data:/data \
  cv-helper
```

浏览器打开 http://127.0.0.1:8000/

## 临时给别人看（电脑需开机）

不想正式上云时，可用内网穿透（如 Cloudflare Tunnel / ngrok）把本机 `8000` 暴露出去。仍建议开 `ACCESS_PASSWORD`。这不是稳定网站，只适合短时演示。

## 已知限制（接受后再上线）

| 点 | 说明 |
|----|------|
| 单库共用 | 无账号体系，所有访问者共用一份 SQLite |
| 免费档休眠 | Render Free 闲置会冷启动，首开较慢 |
| 语音听写 | 依赖浏览器能力；HTTPS 下麦克风权限更顺 |
| 安全 | 访问密码是个人站门槛，不是企业级鉴权 |

## 环境变量速查

| 变量 | 含义 |
|------|------|
| `ACCESS_PASSWORD` | 站点访问密码；空=不启用 |
| `DATABASE_URL` | 默认容器内 `sqlite:////data/cv_helper.db` |
| `LLM_PROVIDER` | `mock` / `openai` |
| `LLM_API_KEY` | 模型 Key |
| `LLM_BASE_URL` / `LLM_MODEL` | 兼容 OpenAI 的接口 |
| `DOUBAO_TTS_API_KEY` | 豆包读题（可选） |
| `PORT` | 云平台一般自动注入 |
